Playlist Flow 1.0.2. If you have 1.0.1, it offers this update by itself (or Help > Check for
updates).

- A shuffle button on the player bar, next to the back button. It shows whether Spotify has
  shuffle on for what's playing (lit when on, greyed out when off) and turns it on or off when
  you click it. Playlist Flow never changes shuffle by itself: only a click on this button does.
- If Spotify's smart shuffle is on, the button says so; turn it off in Spotify.
- With nothing playing, the button shows the last known state and waits for playback to start.
