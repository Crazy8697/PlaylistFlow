Playlist Flow 1.0.1, a fix-up release. If you have 1.0.0, it offers this update by itself (or
Help > Check for updates).

- Double-clicking a track now always plays that track. Playback used to start on a random
  track from the list whenever Spotify's shuffle was on for the device; it now starts exactly
  on the track you clicked, and the tracks below it in Playlist Flow's order follow.
- The toolbar groups (VIEW, SORT, DATA, PLAYLIST) stay where you drag them, including a second
  row, after you close and reopen Playlist Flow. Edit > Reset toolbar layout puts them back.
- Playlists Spotify won't let a Development Mode app read (someone else's, unless it's
  collaborative) now sit in their own "Refused by Spotify" section of the playlist box, with
  the explanation one click away, instead of failing when you open them.
