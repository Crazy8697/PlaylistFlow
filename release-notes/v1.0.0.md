Playlist Flow 1.0.0, the first full release. A free Windows program that orders your Spotify
playlists so they flow, by musical key and tempo. If you have a test build (0.7.0 or later), it
offers this update by itself (or Help > Check for updates).

What's new since 0.9.0:

- FreqBlog lookups follow FreqBlog's usage guidance: one request at a time, always with the
  track name and artist, a short wait (about 45 seconds) before checking tracks that are still
  being analysed, and the full wait FreqBlog asks for whenever it says it's busy.
- While a playlist is being looked up, FreqBlog's own note on tracks still being analysed shows
  in the status bar.
- If your FreqBlog allowance for the month runs out, Playlist Flow stops asking FreqBlog and
  tells you once when it resets.
- Opening a saved playlist while signed in to Spotify brings its track names and artists up to
  date. Nothing else in it changes, and offline it opens exactly as saved.
- Progress messages in the status bar no longer overlap.

BPM and key values are estimates. You need Spotify Premium, your own free Spotify developer app
and your own free FreqBlog key; setup walks you through it.
