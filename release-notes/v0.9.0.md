Test build of Playlist Flow for Windows, on the way to version 1.0.0. If you have 0.8.0, it
offers this update by itself (or Help > Check for updates).

What's new:

- Spotify attribution follows Spotify's current design guidelines: the full Spotify logo in the
  playlist header (it was the icon alone), with its clear space kept at every window size and
  display scaling, and the window's smallest size now leaves room for it.
- Links back to Spotify: OPEN SPOTIFY in the playlist header and the player opens the playlist or
  track in the Spotify app, and so does Open Spotify on a track's or playlist's right-click menu.
  Without the Spotify app installed, the link reads GET SPOTIFY FREE.
- Playlist and now-playing artwork is shown whole, never cropped, with 4 px rounded corners.
- Long playlist and track names are shortened with an ellipsis instead of being cut off, and the
  whole name shows when you point at it.
- When the privacy policy or end user agreement changes, people who are already set up are asked
  to accept the new version once at startup, instead of only the next time they run setup.
- Save description is now a small save button beside the description.

BPM and key values are estimates. You need Spotify Premium, your own free Spotify developer app
and your own free FreqBlog key; setup walks you through it.
